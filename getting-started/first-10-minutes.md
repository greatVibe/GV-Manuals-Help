# First 10 Minutes

Use this guide when you have just opened a GreatVibe node and want to know what
to do first.

## 1. Ask What Is Available

Start by asking:

> What can you see in this workspace, and what should I read first?

This helps the assistant orient around the local files and the help material
available on the node.

## 2. Pick One Small Outcome

Choose one concrete task instead of asking for everything at once.

Good first outcomes include:

- Summarise a folder.
- Review a document.
- Create a checklist.
- Explain a previous gvturn.
- Draft a status update.
- Find the right help guide.

## 3. Give Useful Context

Mention:

- The file, folder, or topic.
- The audience.
- The output you want.
- Any deadline or review standard.
- Whether the assistant should change files or only advise.

Example:

> Review `sample-report.xlsx` for obvious issues. Do not change the file. Give
> me a short checklist of what needs review.

## 4. Read The Gvturn

When the assistant responds, check:

- What was done.
- What was not done.
- Any assumptions.
- Any risks or open questions.
- The next action choices.

If something is unclear, ask for a narrower follow-up.

## 5. Continue With One Next Action

Useful follow-ups include:

- "Explain the recommendation in simpler terms."
- "Show the evidence for that finding."
- "Turn this into a checklist."
- "Make the answer shorter."
- "Now make the safe file changes."

## Quick Checklist

- Ask what is available.
- Pick one concrete outcome.
- Give the file or topic.
- Say whether edits are allowed.
- Review the gvturn before continuing.
- Use one next action at a time.

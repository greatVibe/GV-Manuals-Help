# Welcome To GreatVibe

GreatVibe helps you work with an AI assistant inside a practical workspace. You
can ask for help with documents, files, reviews, summaries, plans, checklists,
troubleshooting, and follow-up work.

The main idea is simple: describe the outcome you want, share the relevant
context, and review the result before using it.

## What You Can Ask For

You can ask GreatVibe to help with work such as:

- Summarising a document or folder.
- Reviewing a file before it is shared.
- Turning notes into a clear update.
- Creating a checklist.
- Finding gaps, risks, or next steps.
- Comparing two options.
- Explaining what happened in a previous turn.
- Preparing a file, report, message, or plan.

Start with the outcome. For example:

- "Summarise this folder and tell me what needs review."
- "Check this spreadsheet for obvious issues before I send it."
- "Turn these notes into a short status update."
- "Explain what this failed turn means and what I should do next."

## How GreatVibe Shows Work

GreatVibe often responds with a card called a gvturn. A gvturn records the work,
the answer, and useful next actions. Some cards include choices you can click to
continue, ask for more detail, approve a direction, or request changes.

Treat a gvturn as a work note: read it, check the recommendation, and use the
next action that matches your goal.

## What To Try First

If this is your first session:

1. Read `first-10-minutes.md`.
2. Ask Mochi to explain the files in your workspace.
3. Ask for one small useful outcome, such as a summary or checklist.
4. Review the gvturn and choose the next action.

## Good First Prompts

- "What can you help me do in this workspace?"
- "List the most useful guides in this help repo."
- "Summarise the files I should read first."
- "Help me write a clear request for the task I want done."

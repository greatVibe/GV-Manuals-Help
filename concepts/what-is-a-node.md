# What Is A Node?

A node is a workspace where GreatVibe can help you work with local files,
manuals, tasks, and conversation history.

You can think of it as the place where an assistant has the context it needs to
help with a specific body of work.

## What A Node May Contain

A node may include:

- Help manuals.
- Project files.
- Previous gvturns.
- Configuration chosen by the workspace owner.
- Tools the assistant can use.

What the assistant can do depends on the node, the available tools, and the
permissions for your session.

## How To Use A Node

Good node-level requests include:

- "What files are available here?"
- "Which guide should I read first?"
- "Summarise this workspace."
- "Review the latest gvturn and tell me what remains."
- "Help me prepare the next action."

## Privacy And Safety

Only include information needed for the task. Do not paste passwords, private
keys, payment details, or sensitive personal information into a general request.

If a task involves sensitive material, ask for a narrow review and confirm what
will be shared before sending anything outside the workspace.

# What Is ACE?

ACE means Agent-Centric Engineering. It is a documentation habit where design
notes live beside the files they explain.

An ACE note tells an assistant what a file or folder is for, who uses it, what
it produces, what it depends on, and what gotchas matter.

## Why ACE Helps

ACE helps because an assistant should not have to guess why a file exists before
working with it.

Good ACE notes can reduce:

- Repeated explanation.
- Accidental design drift.
- Missed constraints.
- Unclear ownership.
- Long code-reading detours.

## What An ACE Note Usually Contains

An ACE note may include:

- Purpose.
- Consumers.
- Produced outputs.
- Key functions or files.
- Dependencies.
- Gotchas.
- Change history.

## When Users Need To Care

You do not need to write ACE notes for ordinary document work. They matter most
when a workspace contains files that assistants may inspect or change.

If you ask an assistant to work on a structured project, it may read ACE notes
before reading the related files.

# Spreadsheet Formatting

Use this guide when preparing a spreadsheet for review, sharing, printing, importing, or ongoing team use.

Good formatting makes a spreadsheet easier to read, reduces mistakes, and helps other people understand the data without needing extra explanation.

## When To Format A Spreadsheet

Format a spreadsheet when:

- The file will be shared with someone else.
- The file will be used more than once.
- The file includes calculations or summaries.
- The file has many columns or rows.
- The file will be printed or exported.
- The file will be used for review or approval.

Do not spend time making a temporary working file look polished unless it helps prevent mistakes.

## Start With The Structure

Before adjusting colours, fonts, or column widths, check the structure.

Confirm that:

- Each column has a clear heading.
- Headings are in a single header row.
- Each row represents one record or item.
- Blank rows are not mixed into the main data table.
- Notes, summaries, and assumptions are separated from the main data.
- Totals and calculations are easy to identify.

A well-structured spreadsheet is easier to filter, sort, validate, and review.

## Header Row

Use the header row to make the file understandable.

Good header rows usually have:

- Short, clear column names.
- Consistent capitalisation.
- No blank header cells.
- No repeated header names unless the meaning is obvious.
- Frozen panes when the table is long.
- Filters enabled when users need to search or narrow the data.

Avoid using merged cells inside the main table header. They can make sorting, filtering, and importing harder.

## Column Widths

Set column widths so the important content can be read without constant resizing.

Use wider columns for:

- Names.
- Descriptions.
- Notes.
- Addresses.
- File names.
- Comments or review feedback.

Use narrower columns for:

- Statuses.
- Dates.
- Amounts.
- Yes or no values.
- Short categories.

If a column contains long notes, wrap the text instead of making the column too wide.

## Alignment

Use alignment consistently.

Recommended defaults:

- Text: left aligned.
- Numbers: right aligned.
- Dates: left or right aligned, but consistent.
- Headings: left aligned or centred, but consistent.
- Status values: centred only when it improves scanning.

Avoid mixing several alignment styles in the same table unless they clearly help readability.

## Number Formats

Apply number formats so values are easy to understand.

Check that:

- Currency values show the correct currency or label.
- Percentages are shown as percentages, not decimals.
- Decimal places are consistent.
- Large numbers use separators when helpful.
- Negative numbers are easy to spot.
- IDs are not accidentally converted into numbers or dates.

If a value is an identifier, code, phone number, or reference number, store and format it as text where possible.

## Date Formats

Use one date format across the file.

Choose a format that is clear to the audience. If day and month order could be misunderstood, use a format that spells out or clearly separates the month.

Check that:

- Dates are not mixed with text values.
- Date columns use the same format.
- Blank dates are intentional.
- Date ranges are labelled clearly.
- Exported dates still display correctly.

## Colours And Emphasis

Use colour sparingly and consistently.

Good uses of colour include:

- Highlighting headings.
- Showing status groups.
- Drawing attention to warnings.
- Separating input areas from calculated areas.
- Marking reviewed or approved rows.

Avoid using colour as the only way to communicate meaning. Add labels or status text so the file remains clear when printed, copied, or viewed by someone with limited colour perception.

## Borders And Shading

Use borders and shading to improve scanning, not to decorate the file.

Helpful options include:

- A subtle fill on the header row.
- Light borders between sections.
- A stronger top border above totals.
- Alternating row shading for wide tables.

Too many heavy borders can make a spreadsheet harder to read.

## Notes And Instructions

If the spreadsheet needs explanation, include it clearly.

Useful notes may include:

- What the file is for.
- Who prepared it.
- The date or period covered.
- Any assumptions.
- Any fields that should not be edited.
- Where reviewers should add comments.

Keep notes outside the main data table so they do not interfere with sorting or filtering.

## Print And Export Layout

If the spreadsheet may be printed or exported, check the layout first.

Review:

- Page orientation.
- Page breaks.
- Margins.
- Header and footer text.
- Repeated header rows.
- Whether columns fit on the page.
- Whether wrapped text is still readable.

Export a test copy if the file will be sent as a PDF.

## Before Sharing

Before sharing a formatted spreadsheet:

- Check that filters are not hiding important rows.
- Confirm formulas still calculate correctly.
- Remove unused sheets if they are not needed.
- Remove temporary notes or draft markings.
- Check that private or irrelevant information is not included.
- Confirm that protected or locked areas behave as expected.
- Save a clean copy if the working file contains unfinished edits.

## Quick Checklist

Before considering the spreadsheet ready:

- Headings are clear and complete.
- Columns are readable.
- Numbers and dates use consistent formats.
- Colours have clear meaning.
- Notes are outside the main data table.
- Totals and formulas are easy to identify.
- Print or export layout has been checked if needed.
- The file has been reviewed for hidden rows, draft notes, and unnecessary information.

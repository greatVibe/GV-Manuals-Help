# Productivity Overview

GreatVibe productivity tools help people work with common business documents such as spreadsheets, text documents, and CSV files. The goal is to make document updates easier to understand, review, and repeat without turning every task into a manual file-editing exercise.

## What You Can Use It For

Use productivity workflows when you need to inspect document structure, update spreadsheet data, adjust formulas, review table content, export information, or keep changes consistent across a document.

This is most useful for structured files where a small change may affect many rows, columns, sheets, or sections.

## Supported Document Types

### Spreadsheets

Use spreadsheet workflows to review sheets, tables, formulas, formats, hidden rows, and cross-sheet references.

### Text Documents

Use text document workflows to review and update document text, headings, tables, and plain content exports.

### CSV and Tabular Files

Use CSV and tabular workflows to inspect rows and columns, update structured data, and prepare clean exports.

## Common Workflows

### Understand a Document

Identify sheets, tables, headings, field names, and sample rows before making changes.

### Update Data

Change values in known cells, rows, columns, or tables while keeping the surrounding structure intact.

### Adjust Formulas

Update formula patterns carefully and check that references still point to the intended ranges.

### Review Results

Check visible changes, expected calculations, and exported views before treating work as complete.

### Keep a Clean History

Record what changed and why so the next reviewer can understand the update.

## Safe Spreadsheet Practices

- Check headers before updating data.
- Treat hidden rows and helper columns as part of the model unless you know they are safe to ignore.
- Prefer formulas that work across spreadsheet versions.
- After formula changes, review a small sample of expected outputs.
- When a sheet has an unusual layout, use visible labels and surrounding context to confirm the intended target.

## When To Ask For Review

Ask for review before publishing or sharing a changed document when:

- Formulas were rewritten
- Financial or operational assumptions changed
- Hidden rows were touched
- Exports will be used outside the team
- A change affects many cells or sections at once

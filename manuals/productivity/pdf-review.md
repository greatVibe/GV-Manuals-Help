# PDF Review

Use this guide before sharing a PDF with another person.

A PDF should preserve the intended layout, include the right content, and avoid exposing draft notes or sensitive information.

## When To Use PDF

PDF is useful when:

- The layout should stay fixed.
- The recipient only needs to read, print, approve, or archive the file.
- The document should look the same on different devices.
- The editable source file should not be shared.

Do not use PDF when the recipient needs to edit the content, work with spreadsheet formulas, or copy structured data into another tool.

## First Open The PDF

Always open the exported PDF before sharing it.

Check:

- The file opens without errors.
- The file name is correct.
- The page count looks right.
- The first page is the intended first page.
- The final page is complete.
- The document is not blank or missing sections.

Do not rely only on the source document preview.

## Layout Checks

Review the PDF layout for:

- Cut-off text.
- Tables split awkwardly across pages.
- Images or charts that are missing, stretched, or cropped.
- Headings separated from their content.
- Page breaks in the wrong place.
- Headers, footers, and page numbers that are missing or incorrect.
- Margins that are too tight for reading or printing.

If the PDF will be printed, check print preview or print settings before sharing.

## Content Checks

Confirm the PDF includes the right content.

Look for:

- Missing pages.
- Duplicate pages.
- Outdated dates or version labels.
- Placeholder text.
- Draft notes.
- Comments or tracked changes that should not be visible.
- Old branding, logos, or contact details.

If the PDF was exported from a longer file, confirm only the intended pages or sections were included.

## Link Checks

If the PDF includes clickable links, test the important ones.

Check that links:

- Open the intended page or file.
- Do not point to private locations.
- Do not expose temporary access links.
- Match the visible link text.

If links are not required, it is still useful to check that visible URLs are correct.

## Data And Table Checks

If the PDF includes data, tables, or charts, confirm:

- Tables fit on the page.
- Column headings are visible.
- Totals and summary values are correct.
- Charts match the data they describe.
- Dates, units, currencies, and percentages are labelled.
- Rounded values are not misleading.

Ask for review when figures affect decisions, reporting, customer communication, or financial outcomes.

## Accessibility Checks

Where possible, make the PDF easier to read by checking:

- Text is selectable rather than only an image.
- Headings are clear.
- Reading order makes sense.
- Images or charts have nearby labels or explanations.
- Colour is not the only way important meaning is shown.
- Font size is readable on screen and in print.

For formal accessibility requirements, ask for a dedicated accessibility review.

## Sensitive Information Check

Before sharing a PDF externally, check for:

- Personal information.
- Private customer details.
- Internal comments or notes.
- Hidden content from the source document.
- Revision marks or suggestions.
- Credentials, tokens, or private access links.
- Commercial information that has not been approved for release.

If the PDF was created from a spreadsheet or presentation, check whether hidden sheets, speaker notes, or comments were included in the export.

## File Size

Check whether the PDF file size is reasonable for sharing.

If the file is very large:

- Confirm images are necessary.
- Remove duplicate pages.
- Export with an appropriate quality setting.
- Consider whether a link or compressed version is more suitable.

Do not reduce quality so much that text, charts, or images become hard to read.

## When To Ask For Review

Ask for review when:

- The PDF will be sent externally.
- The PDF includes customer, financial, legal, or operational information.
- The layout changes after export.
- The document includes many tables, charts, or attachments.
- You are unsure whether comments, tracked changes, or metadata are visible.
- The PDF is final or will be used for approval.

## Quick Checklist

Before sharing a PDF:

- Open the exported PDF.
- Confirm the file name and page count.
- Check the first and last pages.
- Review layout, tables, images, and charts.
- Test important links.
- Remove draft notes and comments.
- Check sensitive information.
- Confirm the file size is reasonable.
- Ask for review when the impact is broad or unclear.

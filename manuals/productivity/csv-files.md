# CSV Files

Use this guide when opening, checking, editing, or sharing CSV files.

CSV files are useful for simple rows and columns, but they do not preserve formulas, formatting, charts, multiple sheets, comments, or layout.

## When To Use CSV

CSV is a good choice when:

- Data needs to move between tools.
- The file only needs plain rows and columns.
- Formatting is not important.
- The recipient needs a lightweight data file.
- The data should be easy to inspect in a text editor or spreadsheet tool.

Do not use CSV when the recipient needs formulas, colours, formatting, charts, protected cells, multiple sheets, or a polished layout.

## Before Opening A CSV

Before making changes, confirm:

- Where the file came from.
- What the rows represent.
- What each column means.
- Whether the first row contains column headers.
- Whether the file should be edited or only reviewed.
- Whether the file includes personal, customer, financial, or operational information.

If the source or purpose is unclear, ask before editing or sharing the file.

## Opening CSV Files

When opening a CSV in a spreadsheet tool, check that:

- Columns split correctly.
- Headers appear in the first row when expected.
- Dates have not changed format.
- Large numbers have not been shortened or rounded.
- Leading zeros are still present when needed.
- Special characters display correctly.

Examples of values that need extra care include account numbers, product codes, postal codes, phone numbers, and IDs.

## Editing CSV Files

When editing a CSV:

- Keep one record per row.
- Keep one field per column.
- Do not add extra title rows above the headers unless required.
- Avoid blank columns unless they are intentional.
- Keep column names clear and consistent.
- Do not rely on cell colours or formatting to explain meaning.

Remember that CSV saves plain values only. Formatting changes may disappear after saving.

## Dates And Numbers

Dates and numbers can change when a CSV is opened or saved.

Check for:

- Dates changing from day-month order to month-day order.
- Long numbers displayed in scientific notation.
- Leading zeros removed from codes or IDs.
- Currency symbols removed or treated as text.
- Percentages converted to decimals.
- Rounded values replacing exact values.

If exact formatting matters, review a small sample before sharing the file.

## Missing Or Extra Columns

If a CSV does not look right, check:

- Whether the file uses commas, tabs, or semicolons as separators.
- Whether text values include commas inside quotes.
- Whether line breaks inside text fields are expected.
- Whether empty columns are intentional.
- Whether the export included the intended fields.

Do not delete unusual columns until their purpose is clear.

## Saving CSV Files

Before saving a CSV, confirm that plain values are acceptable.

A saved CSV will not keep:

- Formulas.
- Cell colours.
- Bold, italic, or other formatting.
- Charts.
- Images.
- Comments.
- Multiple sheets.
- Protected cells.

If those features matter, save a spreadsheet copy as well as the CSV.

## Sharing CSV Files

Before sharing a CSV externally, check:

- The file name is clear.
- The file opens correctly after saving.
- The intended rows and columns are included.
- Sensitive information has been removed or approved for sharing.
- Dates, numbers, and IDs still look correct.
- The recipient can use CSV format.

If the file contains personal, customer, financial, legal, or operational information, ask for review before sharing.

## Quick Checklist

Before sharing a CSV:

- Confirm the purpose and audience.
- Check headers, rows, and columns.
- Review dates, IDs, and large numbers.
- Confirm no required formulas or formatting were lost.
- Open the saved CSV again before sending.
- Remove sensitive information unless approved.
- Ask for review when the impact is broad or unclear.

# Sharing Files

Use this guide when preparing to send, upload, or share files with another person or team.

Good file sharing makes it clear what the file is, who should use it, what action is needed, and whether the recipient can safely rely on the content.

## Before Sharing A File

Before you share a file, confirm:

- The file is the correct version.
- The file name is clear.
- The file opens correctly.
- The content is ready for the recipient.
- The file does not include private or irrelevant information.
- The recipient has enough context to understand it.
- The recipient has the right level of access.

If the file is still a draft, make that clear in the file name or message.

## Choose The Right Format

Choose a format that matches how the recipient will use the file.

Common choices include:

- PDF for fixed review, printing, or signed-off material.
- Spreadsheet format for editable tables, calculations, and data review.
- CSV for simple data exchange.
- Document format for collaborative editing.
- Image format for quick visual reference.
- Compressed archive for multiple related files.

Avoid sending editable files when the recipient only needs to read or approve the content.

## Use A Clear File Name

The file name should help the recipient understand the content before opening it.

A useful file name may include:

- Topic or project name.
- Document type.
- Date or period covered.
- Version or status.
- Audience or purpose when needed.

Avoid vague names such as final, latest, new, copy, or updated unless they are part of a clear naming pattern.

## Check The Version

Before sharing, confirm that the file is the version you intend to send.

Check:

- The date in the file name.
- The document title or cover page.
- The most recent edits.
- The approval or review status.
- Whether comments or tracked changes should remain.
- Whether an older copy is still attached or linked elsewhere.

If several people have edited the file, confirm which version is the current one before sharing.

## Review The Content

Open the file and review it from the recipient's point of view.

Look for:

- Draft notes that should be removed.
- Comments that should not be shared.
- Hidden rows, columns, or sheets.
- Placeholder text.
- Broken links.
- Missing attachments or references.
- Private details that are not needed.
- Formatting issues after export.

For important files, ask another person to review before sending.

## Set Access Carefully

If sharing by link, choose the narrowest access that still lets the recipient do what they need.

Common access levels include:

- View only.
- Comment only.
- Edit access.
- Download access.
- Time-limited access.

Use edit access only when the recipient is expected to change the file. Use view or comment access for review, reference, or approval.

## Explain What Is Needed

When sharing a file, include a short message that explains what the recipient should do.

Useful context includes:

- What the file contains.
- Why it is being shared.
- Whether it is draft or final.
- What action is needed.
- The deadline, if there is one.
- Who to contact with questions.

Do not assume the file name alone gives enough context.

## Sharing Multiple Files

When sharing several files, make the set easy to understand.

Consider:

- Grouping related files in a folder.
- Numbering files if they should be read in order.
- Including a short index or cover note.
- Removing duplicate or outdated files.
- Keeping file names consistent.
- Checking that every file opens correctly.

If one file is the main document, make that clear.

## Sending Large Files

For large files, check whether the recipient can receive and open them.

Options include:

- Compressing files into an archive.
- Sharing a folder link instead of attachments.
- Splitting large exports into smaller files.
- Sending a PDF instead of an editable source file.
- Removing unused sheets, images, or pages.

Do not reduce quality or remove content unless you are sure it is not needed.

## After Sharing

After sharing a file, keep track of what was sent.

Record or confirm:

- The file name.
- The version or date.
- Who received it.
- What access was granted.
- What action was requested.
- Any deadline or follow-up.

If the file is corrected after sharing, tell recipients clearly which version replaces the earlier one.

## When To Ask For Review

Ask for review before sharing when:

- The file will be sent outside your team or organisation.
- The file includes customer, financial, legal, or operational information.
- The file affects a decision or approval.
- The file contains calculations or imported data.
- You are not sure whether comments, hidden data, or draft notes should remain.
- The recipient will rely on the file as final.

## Quick Checklist

Before sharing a file:

- Confirm the file is the right version.
- Use a clear file name.
- Choose the right format.
- Open the file and check the content.
- Remove unnecessary draft notes or private details.
- Set the right access level.
- Explain what action is needed.
- Record what was shared and with whom.

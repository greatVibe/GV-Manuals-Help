# Data Cleanup

Use this guide when preparing spreadsheet, table, or CSV data for review, import, export, or sharing.

Good cleanup makes data easier to understand and reduces the risk of errors caused by inconsistent formatting, missing values, or duplicate records.

## Before Cleaning Data

Before changing data, confirm:

- What the data represents.
- Where the data came from.
- Which columns are required.
- Which rows should be included.
- Whether the file is a source file or a working copy.
- Whether the cleanup changes should be reviewed before sharing.

Keep an unchanged copy of the original data when the source is important or when cleanup could affect decisions.

## Common Cleanup Tasks

Common cleanup tasks include:

- Removing duplicate rows.
- Fixing inconsistent names or labels.
- Standardising dates.
- Standardising numbers, currencies, or percentages.
- Removing extra spaces.
- Filling missing required values.
- Splitting combined values into separate columns.
- Combining related columns when appropriate.
- Removing blank rows or columns.

Make one kind of change at a time when possible. This makes mistakes easier to find and undo.

## Column Headers

Column headers should be clear and consistent.

Check that headers:

- Describe the values in the column.
- Are not blank.
- Are not duplicated.
- Use consistent wording.
- Do not include unnecessary symbols.
- Are easy for another person to understand.

Avoid changing column names when another file, report, or import process depends on the existing names unless the change has been approved.

## Dates

Dates are a common source of confusion.

Check that:

- Date formats are consistent.
- Day and month order is clear.
- Empty date values are intentional.
- Text dates have not been mixed with real date values.
- Time zones or time values are included only when needed.

If dates affect reporting or deadlines, review a sample before applying broad changes.

## Numbers And Amounts

For numbers, check:

- Decimal places are consistent.
- Currency values are labelled clearly.
- Percentages are not mixed with decimals.
- Large numbers have not been rounded accidentally.
- Negative values are shown consistently.
- Units are clear when needed.

Do not remove zeros, decimal places, or symbols until you understand whether they carry meaning.

## Duplicate Records

Before removing duplicates, confirm what makes a row unique.

A duplicate might be based on:

- One ID column.
- A combination of name and date.
- A combination of several fields.
- An exact match across every column.

Do not remove rows just because they look similar. Similar rows may represent different records.

## Missing Values

When values are missing, decide whether they should be filled, left blank, or flagged for review.

Check:

- Whether the field is required.
- Whether a blank means unknown, not applicable, or zero.
- Whether the value can be found from a reliable source.
- Whether filling the value would be a guess.

Do not invent missing values. Ask for review when the correct value is unclear.

## Text Cleanup

For text fields, check:

- Extra spaces before or after values.
- Inconsistent capitalisation.
- Spelling differences in repeated labels.
- Abbreviations used inconsistently.
- Special characters that may not display correctly.

When standardising labels, keep a note of what changed if the file will be reviewed later.

## Reviewing Cleanup Changes

After cleanup, compare the cleaned file with the original.

Review:

- Row count.
- Column count.
- Required fields.
- Totals or summary values.
- A small sample of changed rows.
- Any rows removed or merged.

If totals changed unexpectedly, stop and inspect the cleanup steps before sharing the file.

## When To Ask For Review

Ask for review when:

- Data will be shared externally.
- Cleanup affects customer, financial, legal, or operational information.
- Rows are deleted or merged.
- Missing values are filled from another source.
- Column names are changed.
- The cleanup affects reports, imports, or decisions.
- You are unsure whether a value should be changed.

## Quick Checklist

Before sharing cleaned data:

- Keep or confirm access to the original file.
- Check headers, rows, and columns.
- Standardise dates and numbers carefully.
- Review duplicate rules before deleting rows.
- Do not guess missing values.
- Compare totals before and after cleanup.
- Review a sample of changed records.
- Ask for review when the impact is broad or unclear.

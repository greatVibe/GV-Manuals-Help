# Productivity Troubleshooting

Use this guide when a document update does not look right, spreadsheet data appears incomplete, formulas produce unexpected results, or exported content needs a second check before sharing.

## Data Looks Incomplete

### Symptoms

- Only part of a sheet appears.
- Expected columns are missing.
- A table seems shorter than it should be.

### Checks

- Confirm the selected sheet or table.
- Check for hidden rows or columns.
- Look for merged cells or unusual header layouts.
- Compare against a visible sample in the original document.

### Next Step

Do not update the file until the intended range is clear.

## Formulas Show As Text

### Symptoms

A cell displays a formula such as an equals-sign expression instead of a calculated value.

### Checks

- Confirm the cell format is not plain text.
- Check whether calculation needs to be refreshed.
- Compare neighboring formula cells for expected formatting.

### Next Step

Review a small sample after refresh before sharing the document.

## Formulas Return Unexpected Values

### Symptoms

- Totals are wrong.
- References point to the wrong area.
- A formula returns an error.
- A value changes in a way that does not match the input.

### Checks

- Inspect referenced ranges.
- Check absolute and relative references.
- Confirm hidden or helper rows are included when needed.
- Compare the formula pattern to nearby working cells.

### Next Step

Ask for review before applying the same formula change across a large range.

## Changes Are Not Visible Yet

### Symptoms

A change was requested, but the opened file still appears unchanged.

### Checks

- Make sure you are opening the latest exported file.
- Refresh the document view.
- Confirm the changed sheet or section.
- Check whether calculated values need refresh.

### Next Step

Do not assume the update failed until the latest file and expected location are confirmed.

## A Change Is Not Supported

### Symptoms

A requested edit cannot be applied to the current file type or structure.

### Checks

- Confirm the document type.
- Check whether the file is structured enough for the requested operation.
- Consider whether the content should be converted to a better format first.

### Next Step

Describe the goal rather than forcing a specific edit method.

## CSV and Text Document Limits

CSV files are good for rows and columns but do not preserve formulas, formatting, charts, or rich layout.

Text documents may contain tables and headings, but some visual formatting may need manual review after export.

When layout matters, always inspect the final file before sharing.

## When To Stop And Review

Stop and ask for review when:

- The change affects financial or operational assumptions.
- Hidden rows were touched.
- Formulas changed across many cells.
- Exports will be shared externally.
- The file uses an unusual sheet layout that is not easy to verify.

## Quick Checklist

Before sharing a changed document:

- Confirm the file is current.
- Confirm the sheet, table, or section.
- Check hidden rows and columns.
- Inspect formula references.
- Review a small sample of results.
- Export or refresh before sharing.
- Ask for review if the impact is broad or unclear.

# Exporting Files

Use this guide when saving, exporting, or preparing a file to share with another person.

Exports should be easy to open, easy to read, and suitable for the intended audience.

## Choose The Right Format

Before exporting, decide what the recipient needs to do with the file.

Use an editable format when the recipient needs to make changes.

Use a PDF when the recipient only needs to read, print, approve, or keep a fixed version.

Use CSV when the recipient needs plain rows and columns without formulas, formatting, charts, or layout.

Use images only when the recipient needs a visual snapshot and does not need to copy or edit the text.

## Before Exporting

Confirm:

- The file is the correct version.
- The file name is clear.
- The audience is correct.
- Draft notes and placeholders are removed.
- Required sections, sheets, or pages are included.
- Sensitive information has been reviewed.

If the file contains numbers, formulas, or data tables, review the results before exporting.

## PDF Exports

PDF is useful when layout matters or when the file should not change after sharing.

Before sharing a PDF, check:

- Page breaks are sensible.
- Text is not cut off.
- Tables fit on the page.
- Images and charts are visible.
- Headers, footers, and page numbers are correct.
- Links work if clickable links are expected.
- Comments or tracked changes are not visible unless intended.

Open the exported PDF and review it directly before sending it.

## Spreadsheet Exports

When exporting a spreadsheet, confirm what the recipient needs.

If sharing an editable spreadsheet, check:

- Formulas are correct.
- Hidden rows and columns are intentional.
- Filters are set appropriately.
- Protected cells or sheets behave as expected.
- Unneeded tabs are removed or clearly labelled.

If exporting as CSV, remember that CSV does not preserve formulas, formatting, charts, multiple sheets, comments, or cell colours.

Review the exported CSV if the exact rows and columns matter.

## Document Exports

When exporting a document, check:

- Headings appear in the right order.
- Tables and images stay in place.
- Page breaks do not split important content awkwardly.
- Links and references still make sense.
- Comments, suggestions, or tracked changes are handled correctly.

If the document will be printed, review the print layout before sharing.

## File Names

Use file names that are clear without needing extra explanation.

A good file name usually includes:

- The topic.
- The document type.
- The date or version when helpful.
- A short status such as draft or final when needed.

Avoid vague names such as final, latest, new, or copy unless they are part of a clear naming pattern.

## Sensitive Information Check

Before exporting, check for:

- Hidden sheets, rows, or columns.
- Comments and notes.
- Revision history or tracked changes.
- Personal information.
- Private customer details.
- Internal-only instructions.
- Credentials, access links, or tokens.

If you are not sure whether something should be shared, ask for review before exporting.

## After Exporting

After the export is created:

1. Open the exported file.
2. Confirm the file opens without errors.
3. Check the first and last pages or rows.
4. Review any tables, charts, or images.
5. Confirm the file name is correct.
6. Confirm the file size is reasonable for sharing.
7. Confirm the intended recipient can use the format.

Do not rely only on the source file preview. Always inspect the exported file itself.

## When To Ask For Review

Ask for review when:

- The file will be sent outside your organization.
- The export includes customer, financial, legal, or operational information.
- The file has many pages, sheets, or tables.
- Layout changes after export.
- The export removes formulas or formatting that may be important.
- You are unsure which format the recipient needs.

## Quick Checklist

Before sharing an exported file:

- Choose the right format.
- Use a clear file name.
- Remove draft notes and placeholders.
- Check sensitive information.
- Open the exported file.
- Review layout, tables, charts, and links.
- Confirm the recipient can use the format.
- Ask for review when the impact is broad or unclear.

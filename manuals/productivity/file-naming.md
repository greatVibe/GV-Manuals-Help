# File Naming

Use this guide when naming documents, spreadsheets, exports, images, or folders.

Clear file names make it easier to find the right version, understand what a file contains, and avoid sharing the wrong document.

## Good File Names

A good file name is:

- Clear without opening the file.
- Short enough to scan quickly.
- Specific enough to avoid confusion.
- Consistent with related files.
- Safe to share with the intended audience.

Avoid names that only make sense to the person who created the file.

## What To Include

Most useful file names include two or three of these parts:

- Topic or project.
- Document type.
- Date.
- Version.
- Status.
- Audience or purpose.

Use only the parts that help someone identify the file.

## Dates

When dates matter, use a clear date format.

Recommended format:

YYYY-MM-DD

Examples:

- 2026-07-27
- 2026-07
- 2026-Q3

Use the most specific date that is helpful. Do not add a date if it makes the name harder to understand or if the file already has a clear version number.

## Versions

Use version labels when a file will go through multiple rounds of changes.

Examples:

- v1
- v2
- v3
- draft
- final
- approved

Avoid using final more than once. Names like final-final or latest-final usually make version history harder to trust.

If a file has been approved, use a clear approved label or keep it in an approved folder.

## Status Labels

Status labels can help when several copies exist.

Common labels include:

- draft
- review
- approved
- final
- archived

Do not use a status label unless it is true. Rename draft files when their status changes.

## Separators

Use simple separators consistently.

Recommended separators:

- hyphen
- underscore
- space

Choose one pattern and use it consistently within a folder or project.

Avoid symbols that may cause problems across systems, such as slashes, colons, question marks, asterisks, or quotation marks.

## Examples

Clear examples:

- customer-report-2026-07.pdf
- budget-summary-v2.xlsx
- onboarding-checklist-draft.docx
- product-images-approved.zip
- meeting-notes-2026-07-27.md

Unclear examples:

- final.pdf
- latest.xlsx
- new document.docx
- copy 2.pdf
- notes updated final final.docx

## Folder Names

Folder names should describe the files inside them.

Good folder names are:

- Short.
- Specific.
- Consistent with nearby folders.
- Easy to understand when shared.

Avoid folders called misc, old stuff, temporary, or new unless they are part of a clear cleanup process.

## Sharing Files

Before sharing a file, check that the name is appropriate for the recipient.

Confirm:

- The file name does not reveal private information.
- The status is accurate.
- The date or version is correct.
- The name matches the file content.
- The file extension matches the format.

If a file name includes a customer name, personal detail, or commercial detail, confirm it is appropriate before sharing.

## Renaming Files

Rename a file when:

- The topic changes.
- The status changes.
- The file is prepared for external sharing.
- The name no longer matches the content.
- Several similar copies could be confused.

After renaming, update any links or references that point to the old file name.

## Quick Checklist

Before saving or sharing a file:

- Use a clear topic.
- Add a date or version only when helpful.
- Use one consistent separator style.
- Avoid vague words like latest or final-final.
- Check that the file extension is correct.
- Remove private details from the name unless approved.
- Confirm the name matches the file content.

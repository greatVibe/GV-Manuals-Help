# Work With Files

GreatVibe can help inspect, summarise, review, and prepare files when the files
are available in the workspace.

## Say What Kind Of Work You Want

Common file requests include:

- Summarise this file.
- Compare these files.
- Check this spreadsheet for obvious issues.
- Turn this document into a checklist.
- Prepare a clean status update from these notes.
- Review this export before I share it.

## Say Whether Editing Is Allowed

For advice only:

> Do not change files. Give me a review summary.

For safe edits:

> You may edit Markdown files only. Show a summary afterward.

For high-impact files:

> Give me a plan first. Wait for approval before changing anything.

## Give The File Purpose

A file is easier to review when the assistant knows what it is for.

Mention:

- Audience.
- Deadline.
- Whether the file is draft or final.
- Whether it will be shared externally.
- Any known risk.

## Review Outputs Before Sharing

Before sharing a changed or exported file, check:

- The right file was used.
- Important formatting still works.
- Sensitive information is removed or approved.
- Dates, totals, and names look correct.
- The output matches the intended audience.

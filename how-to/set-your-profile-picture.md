# Set Your Profile Picture

Ask: **“Open Account Admin so I can change my profile picture.”**

```text
konui_console_open_surface({username: "<dashboard-user>", surface: "account-admin", action: "personalisation", requestId: "<current-request-id>"})
```

Open the **Personalisation** tab, choose the profile-picture control, select an image, preview it, and save. The browser's native file picker requires your click; an agent cannot complete that trusted user gesture.

Use an image you are comfortable displaying in GreatVibe. If the saved avatar does not appear immediately in Konui, return to the dashboard or refocus it so personalisation refreshes.
